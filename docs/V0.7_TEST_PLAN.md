## Exact owner-run commands

Use a dedicated installed **test simulator** and copied data, not the only copy of a valuable library. The helper never erases a simulator/store, signs a device, uploads or runs in GitHub CI.

```sh
xcodebuild -version
xcrun simctl list devices available
# Replace with an installed dedicated test simulator UUID.
scripts/validate-v07.sh 'REPLACE_WITH_INSTALLED_TEST_SIMULATOR_UUID'
```

The helper removes the Debug TMDB environment token from the invocation, disables code signing and parallel testing, and runs the full shared scheme in Debug. It writes Xcode version, destinations, complete test log and Tests.xcresult into a printed unique `/tmp/MovieTracker-v07.*` directory. Review the xcresult for skips/failures even after exit 0. Existing production credentials are not requested or used by mocked regression tests.

Then run Release compilation and native benchmarks with the same installed destination:

```sh
xcodebuild build -project MovieTracker.xcodeproj -scheme MovieTracker \
  -configuration Release -destination 'platform=iOS Simulator,id=<SIMULATOR_UUID>' \
  -derivedDataPath /tmp/MovieTrackerV07Release CODE_SIGNING_ALLOWED=NO

xcodebuild test -project MovieTracker.xcodeproj -scheme MovieTracker \
  -configuration Release -destination 'platform=iOS Simulator,id=<SIMULATOR_UUID>' \
  -parallel-testing-enabled NO -only-testing:MovieTrackerTests/V07PerformanceBenchmarks \
  -only-testing:MovieTrackerTests/PersonalStatisticsBenchmarks \
  -only-testing:MovieTrackerTests/LargeLibraryBenchmarks \
  -resultBundlePath /tmp/MovieTrackerV07Benchmarks.xcresult CODE_SIGNING_ALLOWED=NO
```
