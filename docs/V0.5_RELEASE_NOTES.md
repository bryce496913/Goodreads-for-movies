# MovieTracker Beta 0.5.0 (build 12)

**Internal candidate only — NOT READY — BLOCKERS REMAIN.** This is a preparation/stabilization PR, not a distributed or validated beta. See the [release checklist](V0.5_RELEASE_CHECKLIST.md), [test plan](V0.5_TEST_PLAN.md), and [known issues](KNOWN_ISSUES.md).

The V0.5 feature set provides movie/TV Search and details; a local Watchlist, viewing statuses and independent favorites; half-star personal ratings; private reviews and repeat viewing events; cached season/episode watched progress; Library organization; and Home/Profile summaries of saved activity. No fabricated recommendations, community scores or fake user records are added.

This pass repairs stale diary transaction calls, adds a minimal on-device Keychain credential form needed by installed builds, provides a proper provider credits destination with an official logo, adapts Search filtering for accessibility text sizes, prepares shared 0.5.0 version/signing configuration, and expands offline/migration/configuration regression tests. It adds no written-review publishing, cloud account, social profile or analytics service.

Saved text and user progress work locally by design. Discovery and uncached metadata need a network connection and an authorized provider token. After provider/distribution approval, configure that token on the phone in Profile → Settings; save checks syntax and an actual Search confirms authorization. The token is not included in the binary. Changing/removing it leaves personal content intact. Device Keychain behavior and all offline operations still require local execution evidence.

Limitations: no cloud synchronization, user accounts, public reviews, social functionality or export/restore UI. Artwork can disappear from the OS cache; cast is session-only. Changing App ID or uninstalling does not migrate the prior app sandbox. TV progress is separate from series status and diary entries. Statistics describe unique titles and saved events separately; unknown values are not invented.

Unresolved gates include real Debug/Release builds and XCTest, historical migration/device/accessibility evidence, an approved app icon and owned signing identity, actual archive validation, provider/privacy approval, and the API’s six-month retention restriction versus indefinitely saved metadata. No performance numbers or screenshots are claimed. No TestFlight upload or App Store submission has occurred.
